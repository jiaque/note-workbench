# 0.5.5 动效实现与验证

日期：2026-09-20。对应[设计文档](css-motion-design.md)。本页记录实际行为，设计文档仍作为完整协议参考。

## 已实现

- 设置 `noteWorkbench.render.motion.enabled`：布尔值，默认 true，工作区资源级；更改立即下发，不要求重新加载。关闭时保留正文和确定进度。系统减少动态效果偏好优先于启用设置。
- 34 个显式启用预设，主体/入场/悬停参数、可见性与暂停处理；使用 Web Animations API 实现内置时间轴，作者无需编写脚本。内联参数采用 CSS 解析器及类型/范围检查。
- 原有内联样式保留；增加渐变、变换、阴影等受控属性，不开放任意全局 CSS。未知动效按静态内容显示。
- HTML details 和 Markdown Callout 共用箭头、标题、紧凑间距及过渡；支持的宿主使用高度插值，否则保持即时展开与淡入。当前页面切换阅读模式后保留开合；不保存临时开合到源码。
- 作者内联 SVG 过滤后变为临时 data 图片，本地 SVG 引用使用同样链路。保留 viewBox、显式尺寸和允许的布局样式，补齐图片字体/颜色基线，主题变化更新图片。
- SVG CSS 关键帧和受控 animate/animateTransform/animateMotion/set 自动播放；脚本、事件属性、外部资源、foreignObject、事件触发式动画及修改链接的动画被过滤。
- 点击 SVG 仍编辑原始源码，浮层显示图片；不将 data URL 写入 Markdown。暂停或关闭时显示静态基础态，菜单可重新播放。
- PDF 使用相同装饰构造和静态 SVG，确定进度显示目标值，折叠内容展开。

## 验证

- 57 项单元测试及 TypeScript 检查通过；覆盖既有编辑/表格/语法与新增 CSS 参数、SVG 引用、关键帧、静态输出、脚本/URL 过滤和资源限额。
- `npm run test:motion` 启动浏览器页，验证 34 个预设实例、悬停、设置开关、暂停、65% 进度、折叠恢复、SVG 图片解码/隔离、静态 PDF 装饰；浏览器报告 PASS。
- 真实编辑器样例已验证 SVG 点击后源码可编辑且浮层展示图片；切换阅读时 HTML 折叠态保持关闭，Markdown 折叠态保持展开，进度保持 65%，作者 SVG 不在正文 DOM 中。
- 隔离 VS Code 宿主验证默认开启及关闭设置即时下发；真实编辑、保存、撤销重做、源码补全、多视图同步、默认打开和 Auto Save 回归通过。
- 实际 PDF 导出通过既有中文/公式/Mermaid/多页表格样例、图片/取消/缺图处理及新增 Effects.md 样例。生成成功不等于每一种自定义 SVG 的静态构图均合适。

## 范围与限制

- 开关替代早期设计里的 system/on/off 三值设置：本版默认开启且始终尊重系统减少动态效果偏好。
- click 触发动效在阅读视图使用；实时预览中点击正文优先进入源码编辑。悬停动效在两种模式可见；链接、summary、表格等自身交互优先。
- SVG 图片在离屏、后台或关闭动效时显示静态基础态，恢复时可能从头播放；不提供任意帧跳转或精确冻结当前帧。静态图使用作者的基础构图，不自动猜测操作演示最终帧。
- SVG 不支持图内鼠标交互、内嵌位图或任意 CSS at-rule；CSS 样式块目前支持普通规则及 keyframes。远程 SVG 继续是受远程图片设置控制的普通 img，不属于本地文件过滤承诺。
- SVG 输入上限 500KB、5000 个解析节点、100 个声明式动画；单属性最长 30000 字符，画布显式尺寸最多 4096，滤镜模糊数值最多 20。超过输入/节点/动画限额时保留源码并提示，不退回内联执行。
- 安全性依赖过滤、图片上下文及 CSP 多层约束；不宣称绝对安全或已完成独立安全审计。跨平台、所有滤镜组合和大量并行动画仍需要进一步性能与兼容验证。

样例位于 `test/fixtures/vault/Effects.md`。修改文档只会保存作者源码，不会保存播放时间、临时装饰或图片数据。
