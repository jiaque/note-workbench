# Obsidian 格式兼容与验收清单

基线日期：2026-09-18。用户要求是覆盖 Obsidian 官方文档的笔记格式，业务报告只是回归样本。不能用报告看起来相似、或保留了未渲染源码，代替完整兼容验收。

## 官方依据

- [基础格式](https://obsidian.md/help/syntax)：标题、段落、强调、高亮、列表、任务、引用、代码、图片、脚注、注释、转义。
- [高级格式](https://obsidian.md/help/advanced-syntax)：表格、公式、Mermaid 及图中笔记链接。
- [Obsidian Flavored Markdown](https://obsidian.md/help/obsidian-flavored-markdown)：原生扩展语法以及 HTML 内不递归解析 Markdown 的边界。
- [Callout](https://obsidian.md/help/callouts)：类型、别名、富文本标题、折叠、嵌套、未知类型回退。
- [内部链接](https://obsidian.md/help/links)、[嵌入](https://obsidian.md/help/embeds)：整篇、标题、嵌套标题、块、附件、循环与缺失目标。
- [标签](https://obsidian.md/help/tags)、[属性](https://obsidian.md/help/properties)：嵌套标签、YAML 类型、显示模式、cssclasses。
- [表格官方发布说明](https://obsidian.md/changelog/2023-12-26-desktop-v1.5.3/)：边缘增行列、上下文菜单、重排，仍保存为纯文本。

## 尚未达成的完整替代品能力

这些内容没有从首版目标中移除，也不能以当前渲染能力已实现为理由标成完成：

- 连续 Live Preview 编辑、完整键盘/输入法和无损富文本编辑；当前仍是块源码草稿并显式应用。
- 真实宿主的保存、撤销、多窗口、来源变化刷新、离线资源策略，及大笔记库性能验收。
- 搜索结果嵌入（query 代码块）、属性的语义查询、标签索引、属性类型编辑器与自动补全。
- 图谱、反向链接、补全与工作区索引；表格全部键盘交互和边界验收。
- Obsidian 默认主题的逐控件视觉核对、深色/高对比度、全部 Mermaid 图类型与媒体编码样本。

任意第三方主题/插件的自定义语法没有有限的“全部”清单；它们需另列兼容项。官方格式和用户已确认的首版功能均保留在验收范围，不以此排除核心能力。

## 持续回归办法

1. `npm test`：语法、源码保真、嵌入目标、安全过滤和结构编辑。
2. `test/fixtures/vault/Formatting.md`：合成展示笔记；附件由 `scripts/create-media-fixtures.mjs` 生成。代码和资源全部离线打包。
3. 用户的 Markdown/HTML 只读对照：正文、折叠、表格逐单元格、图表节点和样式；用户原文不进入 Git 或安装包。
4. 同一笔记在阅读、编辑视图切换不应改变内容或表格格式；保存/重开后比较源文件差异。
5. `npm run test:extension`：真实宿主验收。当前本机更新锁阻止测试窗口启动，不能记录为通过。
