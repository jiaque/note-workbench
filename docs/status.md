最终构建再次对照业务报告：14 个标题文字、5 张表格逐单元格文字、15 个 Callout 标题和初始折叠状态、3 张 SVG 内部节点文字与属性均一致。全局主题、字号间距仍可不同，不记录为逐像素一致。0.2.0 VSIX 已成功安装到当前用户 VS Code，CLI 列表确认版本；窗口加载新代码需重新加载窗口。

## 0.1.1 渲染一致性修复

- 移除正文上方品牌栏、重复文件名与元数据提示条，笔记操作收进右上角省略号；YAML 仍可通过全文源码编辑。
- 表格行列操作收进右键/省略号菜单，边缘悬浮加行加列，保留行列拖动；单元格展示安全渲染后的富文本。
- 支持 Callout 标题、嵌套及 `+` 展开、`-` 折叠；恢复允许列表内的 HTML 内联样式与静态 SVG 图形。
- 页内锚点在当前文档滚动；Windows 绝对路径链接保留显示，打开仍受笔记库根目录限制。
- 用户提供的 Markdown/HTML 对照：全部标题、5 张表格的逐单元格文字、15 个 Callout 标题与初始开合状态一致；3 张 SVG 内部节点的文字和属性一致。用户业务文件只读加载，不纳入仓库或 VSIX。
- 浏览器验证折叠、锚点、右键菜单与新增行；修复菜单焦点切换导致点击丢失的问题。13 项核心回归测试通过。
- 内容和支持的样式恢复不等于任意 HTML 网页逐像素复刻：独立 HTML 的全局 CSS、打印工具、脚本不自动载入；正文仍适应 VS Code 主题和窗口宽度。静态 SVG 为允许列表，外部引用和活动内容不支持。

依据：[Obsidian 表格官方发布说明](https://obsidian.md/changelog/2023-12-26-desktop-v1.5.3/)、[高级格式语法](https://obsidian.md/help/advanced-syntax)、[Callout 文档](https://obsidian.md/help/callouts)。目前尚未实现完整 Obsidian Live Preview 编辑体验。

## 当前实现边界

1. 可视化正文连续输入还未实现，目前通过渲染块旁的“编辑”进入源码片段。单元格显示富文本，但编辑时仍为源码片段，完整行内富文本编辑尚待实现。
2. 图谱、反向链接、补全、query 嵌入和语义索引仍待开发；Wiki 链接、标题/块引用和嵌入已有实现，完整验收尚待完成。
3. HTML 表格仅处理可定位的普通矩形结构；colgroup、省略闭合标签、混合 HTML 块内表格等仍需扩展。
4. 基础拖动已实现，复杂自动滚动、窗口失焦取消、焦点恢复及全部拖动边界还需系统验收。
5. 未应用的草稿不是 VS Code 文本文档内容；关闭/恢复、自动保存与无闪烁撤销需要进一步设计及真实宿主验证。
6. 公式和 Mermaid 基础渲染不等同于全部稳定图类型/数学语法验证。未执行大库、100×20 表格和完整 IME/可访问性验收。
7. 目前仅有笔记文件列表，列表上限 2,000 项；正式索引、取消和增量图谱尚待实现。
