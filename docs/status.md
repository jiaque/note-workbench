## 0.5.4 默认编辑器与阅读间距

Markdown 自定义编辑器优先级改为 default；遵循 VS Code 既有编辑器关联和多候选选择，不覆盖用户设置。README 已说明已有默认关联的切换方法。

阅读视图保留源码空行产生的 10px 间距，采用与实时预览一致的 flow-root 块容器、表格布局及顶部内边距；表格隐藏操作入口但保留布局占位，避免换行变化。早期合成样例的 8 个非空正文块位置和高度一致，阅读区可编辑元素和按钮数量为 0；本轮进一步消除了表格列宽的小数差异，最新表格及默认打开验收以上节为准。

## 0.5.3 块内光标定位修复

渲染表格的上下外边距及块内折叠外边距未计入 CodeMirror 的 widget 边框盒高度，导致后续源码行的坐标与实际 DOM 位置错位。已在块级 widget 外增加零外边距的 flow-root 容器，将原有文档间距计入测量；行内 widget 与标题源码样式保持原行为。

浏览器复现旧版 Callout 按一次上方向键跳到文档开头；修复后验证块内再次点击、上下往返、继续输入及同步。新增 `npm run test:caret`（先构建，再打开 http://127.0.0.1:4318），在真实浏览器中检查表格后 Callout 的鼠标命中位置、三轮上下移动、渲染回执和源码不被修改，页面应显示 PASS。38 项单元测试及类型检查通过；浏览器测试不等同于 VS Code 宿主实机验收。
